# Daily cybersecurity news: reusable agent prompt

> This is a cleaned-up template describing the job's behavior, not an export of the live Hermes prompt.

Review the latest cybersecurity stories from these public sources:

- BleepingComputer: https://www.bleepingcomputer.com/feed/
- The Hacker News: https://thehackernews.com/feeds/posts/default
- Krebs on Security: https://krebsonsecurity.com/feed/
- CISA advisories: https://www.cisa.gov/cybersecurity-advisories/all.xml

Select **3–5 news items**, preferably from approximately the past 48 hours. Give priority to actively exploited vulnerabilities, significant breaches, supply-chain attacks, high-impact advisories, and practical defensive actions.

When relevant, connect stories to club interests, including password cracking and GPU computing; Linux and SSH; wireless and telecommunications security; capture-the-flag practice; patching; and AI/LLM security.

For each item include:

1. A short headline.
2. A plain-language explanation of why it matters.
3. An original, working source link taken from the fetched content.

Keep the overall Discord message concise (ideally fewer than 1,900 characters). Avoid repeating the same story across sources. Do not invent details, publication dates, links, or claims. Do not include names of individual club members, internal systems, or private network information.

Close with a short note naming the sources checked.

If the feeds are unavailable or no appropriate recent stories can be confirmed, say so instead of fabricating a digest.
